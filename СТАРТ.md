## ⚠️ Если что-то не так:

### Ошибка "EADDRINUSE" (порт 3000 занят):
```powershell
# Найти процесс
netstat -ano | findstr :3000 | findstr LISTENING

# Убить процесс (замените <PID> на нужный)
taskkill /F /PID <PID>

# Запустить заново
npm run dev
```

### Видите ошибку "jwt malformed":
```javascript
localStorage.clear();
location.reload();
```

### Entry Page не показывается:
1. Откройте режим инкогнито
2. Очистите кеш браузера (Ctrl+Shift+Delete)
3. Проверьте консоль на ошибки

### WebSocket ошибки:
Это нормально до авторизации. После нажатия "Start" ошибки исчезнут.
