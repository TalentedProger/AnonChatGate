## 🔧 Исправленные проблемы

### 1. ✅ Цвет текста в счетчике участников

**Проблема:** Слова "участников" и "онлайн" сливались с фоном

**Решение:**
- Текст теперь светло-серый (`text-zinc-200`) - почти белый
- Цифры остались цветными: 🔵 синий (всего) и 🟢 зеленый (онлайн)
- Добавлено жирное начертание цифр (`font-medium`)

**Пример:** `120 участников | 72 онлайн`
- "120" - синий жирный
- "участников" - светло-серый
- "72" - зеленый жирный  
- "онлайн" - светло-серый

---

### 2. ✅ Затемнение фонового изображения при скролле

**Проблема:** Темная overlay (40% затемнение) отображалась только на высоту экрана, при прокрутке исчезала

**Решение:** 
- Использован CSS `linear-gradient` вместо отдельного div
- Затемнение теперь часть фона, прокручивается вместе с контентом
- Постоянное затемнение по всей высоте чата

**Техническая реализация:**
```tsx
background: `linear-gradient(rgba(0, 0, 0, 0.4), rgba(0, 0, 0, 0.4)), url(${image}) center/cover fixed`
```

**Преимущества:**
- ✅ Overlay видно всегда при прокрутке
- ✅ Лучшая производительность (нет лишнего DOM элемента)
- ✅ Более надежное решение

---

### 3. ✅ Увеличены отступы между сообщениями

**Изменение:** С `space-y-4` на `space-y-6`

**Результат:**
- Сообщения не кучкуются
- Лучшая визуальная разделенность
- Более комфортное чтение
- Легче различать отдельные сообщения

---

### 4. ✅ Исправлено несоответствие данных участников

**Проблема:**
- На странице **Chats** (список чатов): показывались реальные данные с сервера
- На странице **Chat** (внутри чата): показывались поддельные данные

**Что было:**
```tsx
// chat.tsx - неправильно
<span>{onlineCount}</span> участников |   // показывали онлайн как всего
<span>{Math.floor(onlineCount * 0.6)}</span> онлайн  // вычисляли 60%
```

**Что стало:**
```tsx
// chat.tsx - правильно
<span>{totalUsers}</span> участников |   // реальное общее число
<span>{onlineCount}</span> онлайн        // реальное число онлайн
```

**Откуда берутся данные:**
- Сервер отправляет через WebSocket:
  - `totalUsers` - общее количество пользователей
  - `count` (onlineCount) - количество онлайн

- Раньше клиент игнорировал `totalUsers`
- Теперь использует оба значения

**Проверка соответствия:**
1. Откройте страницу Chats → увидите числа (например, 120 / 72)
2. Откройте чат → должны увидеть те же числа
3. Числа должны совпадать! ✅

## 📊 Технические детали

### Цвета Tailwind CSS
- `text-zinc-200` - светло-серый (почти белый) для обычного текста
- `text-blue-400` - синий для общего количества
- `text-green-400` - зеленый для онлайн
- `font-medium` - среднее начертание (полужирное)

### CSS Linear Gradient
```css
background: linear-gradient(
  rgba(0, 0, 0, 0.4),  /* верхний слой затемнения */
  rgba(0, 0, 0, 0.4)   /* нижний слой затемнения */
), url(image.jpg) center/cover fixed;
```

### Tailwind Spacing
- `space-y-4` = 1rem (16px) между элементами
- `space-y-6` = 1.5rem (24px) между элементами
- Увеличение на 50% для лучшей читаемости

### WebSocket Message Format
```typescript
{
  type: 'online_count',
  count: 72,        // онлайн сейчас
  totalUsers: 120   // всего зарегистрировано
}
```
