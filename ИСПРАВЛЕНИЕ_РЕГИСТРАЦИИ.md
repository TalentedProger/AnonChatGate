### 6. Исправлена проблема с токеном
**Проблема:** `jwt malformed` - токен не сохранялся правильно

**Решение:**
1. Entry Page теперь правильно сохраняет токен через `auth.setAuthData(authData)`
2. Registration проверяет наличие токена при загрузке
3. Если токена нет → редирект на `/entry`
4. Логирование для отладки:
   ```javascript
   console.log('[Registration] Authenticated as:', auth.user.anonName);
   console.log('[Registration] Token exists:', !!auth.token);
   ```

## 🚀 Как протестировать

### Шаг 1: Очистить localStorage

Откройте DevTools → Application → Storage → Local Storage → Очистить всё

### Шаг 2: Обновить страницу

Вы должны увидеть Entry Page:
- Логотип "A" в градиентном круге
- Заголовок "AguGram - первая соцсеть для студентов"
- Подзаголовок "Сообщество, где быть внутри — уже привилегия"
- Кнопка "Start" с градиентной границей
- "Created by secret" внизу

### Шаг 3: Нажать "Start"

**В dev-режиме:**
1. Создаётся новый пользователь
2. Открывается страница регистрации
3. В консоли:
   ```
   [Entry] Using dev authentication
   [Entry] Dev auth data: {...}
   [Entry] Dev auth successful
   [Registration] Authenticated as: Student_X
   [Registration] Token exists: true
   ```

**В продакшене (Telegram):**
1. Используется Telegram initData
2. Создаётся пользователь
3. Открывается регистрация

### Шаг 4: Заполнить регистрацию

**Шаг 1/3: Личная информация**
- Ваше имя (обязательно)
- Пол (обязательно)
- Курс (обязательно)
- Направление (обязательно)
- О себе (необязательно)

**Шаг 2/3: Социальные сети**
- Telegram (необязательно)
- Instagram (необязательно)
- ВКонтакте (необязательно)
- Можно пропустить

**Шаг 3/3: Фотографии**
- Аватар (необязательно)
- Фото 1-3 (необязательно)
- Можно пропустить

### Шаг 5: Создать аккаунт

После нажатия "Создать аккаунт":
1. Профиль сохраняется
2. Перенаправление на главную страницу `/`
3. Пользователь авторизован
