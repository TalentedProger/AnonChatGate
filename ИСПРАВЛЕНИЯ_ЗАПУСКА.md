# ✅ Исправление ошибок запуска

## 🔧 Проблемы и решения

### 1. **Синтаксическая ошибка в `websocket.ts`**

**Ошибка:**
```
ERROR: Unexpected "catch"
server/websocket.ts:232:6
```

**Причина:**
В функции `handleAuth` был блок `catch` без соответствующего `try`.

**Исправление:**
Добавлен блок `try {` в начало функции `handleAuth`:

```typescript
async function handleAuth(ws: AuthenticatedWebSocket, message: any) {
  try {  // ← ДОБАВЛЕНО
    const { token } = message;
    // ... весь код аутентификации
  } catch (error) {
    // ... обработка ошибок
  }
}
```

**Файл:** `server/websocket.ts` (строка 158)

---

### 2. **Команда `start` не работала на Windows**

**Ошибка:**
```
"NODE_ENV" не является внутренней или внешней
командой, исполняемой программой или пакетным файлом.
```

**Причина:**
Команда `NODE_ENV=production node dist/index.js` использует Unix-синтаксис, который не работает в PowerShell.

**Исправление:**
Упрощена команда `start` в `package.json`:

**Было:**
```json
"start": "NODE_ENV=production node dist/index.js"
```

**Стало:**
```json
"start": "node dist/index.js"
```

**Файл:** `package.json` (строка 9)

## ⚠️ Важно:

### Если порт 3000 занят:

1. **Найти процесс:**
   ```powershell
   netstat -ano | findstr :3000 | findstr LISTENING
   ```

2. **Убить процесс:**
   ```powershell
   taskkill /F /PID <PID>
   ```

3. **Запустить заново:**
   ```bash
   npm run dev
   ```

### Если возникают ошибки при запуске:

1. Проверьте `.env` файл (все переменные должны быть заполнены)
2. Проверьте подключение к PostgreSQL
3. Убедитесь, что ngrok запущен
4. Очистите `node_modules` и переустановите:
   ```bash
   rm -rf node_modules
   npm install
   ```
