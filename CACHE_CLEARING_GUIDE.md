# Руководство по очистке кэша Telegram Mini App

## Проблема

Telegram агрессивно кэширует Mini Apps, что может привести к показу старых версий приложения даже после обновления кода.

## Что было исправлено

### 1. **Удалены все заглушки пользователей**
- ✅ Удалена заглушка `student_999999` с id: 999999 из `chat.tsx`
- ✅ Исправлена WebSocket аутентификация - теперь передается реальный JWT токен
- ✅ Entry page использует persistent dev user ID вместо случайных значений

### 2. **Добавлено версионирование приложения**
- ✅ Версия `v2.0.0` в HTML meta-тегах
- ✅ Автоматическая очистка localStorage при смене версии
- ✅ Timestamp в URL мини-приложения от Telegram бота

### 3. **Настроены заголовки кэширования**
- ✅ HTML файлы: `no-cache` (всегда загружаются заново)
- ✅ JS/CSS с хэшем: долгое кэширование (безопасно, т.к. имя меняется)
- ✅ Vite config настроен на генерацию хэшей в именах файлов

### 4. **Исправлена аутентификация**
- ✅ Chat страница теперь требует реальной аутентификации
- ✅ WebSocket получает валидный JWT токен через `auth.getValidToken()`
- ✅ Автоматический redirect на `/entry` если нет аутентификации

## Как использовать обновленное приложение

### Для Production (Telegram Bot)

1. **Пересоберите проект:**
   ```powershell
   npm run build
   ```

2. **Перезапустите сервер:**
   ```powershell
   npm start
   ```

3. **В Telegram боте:**
   - Бот автоматически добавляет timestamp к URL при каждом запуске
   - Кнопка "Открыть приложение" всегда загружает свежую версию

4. **Если всё равно видите старую версию:**
   
   **Метод 1: Полная очистка кэша Telegram (iOS/Android)**
   - Зайдите в Settings → Data and Storage → Storage Usage
   - Нажмите "Clear Cache"
   - Закройте Telegram полностью (свайп вверх)
   - Откройте Telegram заново
   - Запустите бота снова

   **Метод 2: Переустановка Telegram**
   - Удалите Telegram полностью
   - Установите заново
   - Войдите в аккаунт
   - Запустите бота

   **Метод 3: Используйте Telegram Web**
   - Откройте https://web.telegram.org
   - Нажмите Ctrl+Shift+R для жесткой перезагрузки
   - Запустите бота

### Для Development режима

1. **Запустите dev сервер:**
   ```powershell
   npm run dev
   ```

2. **Очистка при каждом запуске:**
   - Приложение автоматически очищает localStorage при изменении версии
   - Dev user ID сохраняется для удобства разработки

3. **Принудительная очистка:**
   - Откройте DevTools (F12)
   - Application → Local Storage → удалите всё
   - Перезагрузите страницу (Ctrl+R)

## Технические детали

### Версионирование

Версия приложения: `2.0.0`

При изменении версии в `client/src/main.tsx`:
```typescript
const APP_VERSION = '2.0.0'; // Измените это число для очистки кэша
```

Все localStorage (кроме `dev_user_id`) будут очищены автоматически.

### Структура аутентификации

1. **Entry Page** → Создает/получает пользователя
2. **Auth Manager** → Управляет токенами в localStorage
3. **Protected Routes** → Проверяют наличие токена
4. **Chat Page** → Использует токен для WebSocket

### Заголовки кэширования

**HTML (`index.html`):**
```
Cache-Control: no-cache, no-store, must-revalidate
Pragma: no-cache
Expires: 0
```

**JS/CSS с хэшем (например `main-abc123.js`):**
```
Cache-Control: public, max-age=31536000, immutable
```

**Остальные ассеты:**
```
Cache-Control: public, max-age=3600
```

## Проверка правильной работы

### 1. Проверьте в консоли браузера:

```javascript
// Должна быть новая версия
localStorage.getItem('app_version') // "2.0.0"

// Должны быть токены (если авторизованы)
localStorage.getItem('chat_auth_state')

// Dev user ID (только в development)
localStorage.getItem('dev_user_id')
```

### 2. Проверьте Network tab:

- `index.html` должен загружаться с `200` (не `304 Not Modified`)
- JS файлы должны иметь хэш в имени: `main-[hash].js`

### 3. Проверьте аутентификацию:

- После запуска приложения должен появиться пользователь с уникальным ID
- Имя пользователя: `Student_[ID]` где ID - автоматически сгенерированный номер
- WebSocket должен подключаться с валидным токеном

## Типичные проблемы

### ❌ "WebSocket auth error: No token"
**Причина:** Старый код в кэше  
**Решение:** Очистите кэш Telegram, пересоберите проект

### ❌ Всё еще вижу Student_999999
**Причина:** Telegram кэширует старую версию  
**Решение:** Полная очистка кэша Telegram (см. выше)

### ❌ Постоянно редиректит на /entry
**Причина:** Токены не сохраняются  
**Решение:** Проверьте localStorage, убедитесь что `chat_auth_state` сохраняется

### ❌ "Profile incomplete" при отправке сообщений
**Причина:** Профиль не заполнен  
**Решение:** Заполните профиль на странице регистрации
