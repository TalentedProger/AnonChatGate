# 🔧 Устранение ошибок запуска

## ✅ Исправленные проблемы

### 1. Ошибка `polling_error: EFATAL`

**Причина:** Telegram Bot API не может установить соединение через polling из-за:
- Другого экземпляра бота с тем же токеном
- Проблем с сетью
- Временной недоступности Telegram API

**Что было сделано:**
- Добавлена обработка ошибок polling
- Добавлен graceful shutdown при остановке сервера
- Настроены таймауты и интервалы опроса
- Сервер теперь продолжает работать даже при ошибках бота

**Файл:** `server/telegram-bot.ts`

---

### 2. Предупреждение `NODE_TLS_REJECT_UNAUTHORIZED`

**Причина:** Небезопасная настройка SSL, которая отключала проверку сертификатов.

**Что было сделано:**
- Удалена строка `NODE_TLS_REJECT_UNAUTHORIZED = '0'`
- База данных Neon правильно настроена с `sslmode=require`

**Файл:** `server/db.ts`

---

## 🚨 Как исправить ошибку EFATAL

### Метод 1: Остановить другие экземпляры бота

**Проблема:** Возможно, запущен другой экземпляр бота с тем же токеном.

**Решение:**

```powershell
# Windows - найти и остановить процессы node
Get-Process node | Stop-Process -Force

# Или используйте Task Manager:
# Ctrl+Shift+Esc → Подробности → Завершить все процессы node.exe
```

После этого запустите сервер снова:
```bash
npm run dev
```

---

### Метод 2: Перезагрузить ngrok

**Проблема:** ngrok может потерять соединение или использовать старую сессию.

**Решение:**

1. Остановите ngrok (Ctrl+C в терминале ngrok)

2. Запустите заново:
```bash
ngrok http 3000
```

3. Скопируйте новый URL (например: `https://xxx-yyy-zzz.ngrok-free.app`)

4. Обновите `.env`:
```env
WEBAPP_URL=https://новый-ngrok-url.ngrok-free.app
```

5. Перезапустите сервер:
```bash
npm run dev
```

---

### Метод 3: Проверить Telegram Bot Token

**Проблема:** Токен бота может быть неправильным или отозванным.

**Решение:**

1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather)

2. Отправьте `/mybots`

3. Выберите вашего бота

4. Нажмите "API Token" → "Regenerate" (если нужно)

5. Скопируйте новый токен

6. Обновите `.env`:
```env
TELEGRAM_BOT_TOKEN=новый_токен_здесь
```

7. Перезапустите сервер

## 🔍 Диагностика проблем

### Проверка 1: Бот отвечает?

```bash
# Откройте Telegram
# Найдите вашего бота
# Отправьте /start
```

**Ожидаемый результат:** Бот отправляет приветственное сообщение с кнопкой "🚀 Открыть приложение"

**Если нет ответа:**
- Проверьте, что сервер запущен
- Проверьте логи сервера на ошибки
- Убедитесь, что токен бота правильный

---

### Проверка 2: ngrok работает?

```bash
# В отдельном терминале должен быть запущен ngrok
ngrok http 3000
```

**Должно быть видно:**
```
Forwarding   https://xxx.ngrok-free.app -> http://localhost:3000
```

**Если ngrok не запущен:**
```bash
# Установите ngrok (если нужно)
choco install ngrok

# Или скачайте с https://ngrok.com/download

# Запустите
ngrok http 3000
```

---

### Проверка 3: Сервер запущен на порту 3000?

```bash
# Windows
netstat -ano | findstr :3000

# Должна быть строка типа:
# TCP    0.0.0.0:3000    0.0.0.0:0    LISTENING    12345
```

**Если порт занят другим процессом:**
```powershell
# Найти процесс на порту 3000
$processId = (Get-NetTCPConnection -LocalPort 3000).OwningProcess
Stop-Process -Id $processId -Force
```

## ⚠️ Важные заметки

### О ngrok бесплатной версии:

- URL меняется при каждом запуске
- Нужно обновлять `.env` каждый раз
- Есть лимит на количество соединений

**Решение для постоянного URL:**
```bash
# Платная версия ngrok с постоянным доменом
ngrok http 3000 --domain=your-domain.ngrok-free.app
```

---

### О polling ошибках:

Ошибка `EFATAL` **не критична**. Сервер продолжит работать, и бот может работать нормально через некоторое время.

**Что происходит:**
1. Бот пытается подключиться к Telegram API
2. Если соединение не удается, выводится ошибка
3. Бот автоматически повторяет попытки
4. Сервер остается активным

**Когда бот точно не работает:**
```
[Telegram Bot] Fatal polling error - bot may not receive updates
```

В этом случае используйте методы 1-3 выше.
